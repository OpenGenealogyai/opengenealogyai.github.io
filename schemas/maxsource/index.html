MAXGEN schema · v2.1

MaxSource

One MaxSource is one work, collection or repository.

Download MaxSource (2.1) All versions https://opengenealogyai.org/schemas/maxgen/v2/source.schema.json

SHA-256 c46fe41a47a681c20634e00d616a31e084db4ba807bac0a80ee58d284f5d6a16

Definition

MAXGEN 2.0 -- One MaxSource is one work, collection or repository that documents come from or are held by (a book, a periodical, a census collection, a microfilm publication, a family Bible, an archive, a library or a website), with what it covers and how to search it.

The schema's own description, word for word.

Fields

The top-level fields of a MaxSource document. Parts shared by every schema (the date block, the place block, the evidence link, the claim header and others) are defined once in the shared building-blocks file.

FieldTypeMeaning
source_id requireduuidThis source's own id: a random UUID created once by the writer and never reused.
name requiredstringThe source's name in plain words, such as a made-up 'Tumblebrook parish registers, 1801-1900'.
source_type requiredenumWhat kind of source this is.
source_type_as_written stringThe kind of source in the writer's or the other program's own words, given when source_type is other.
redistribution_license requiredlicenceWhether this source entry may be shared (unclear means ask, never guess); a tier2-private entry never appears in any open dataset, share, export, public embedding or commit.
is_living_flag requiredbooleanLiving A floor: true when this source entry names someone who may be alive, such as a privately held family Bible (unsure means true; credits never set it); true requires tier2-private.
source_url uriThe source's own address, when it has one; optional (a book or a family Bible has none) and never invented.
address place_refMAXGEN 2.1 (G-14): where an archive or library is: its postal address in address_as_written, its town in place_as_written, and the MaxPlace in place_id; only on a source whose source_type is archive or library, or other
parent_source_id uuidThe larger MaxSource this one is part of, such as the collection that holds this series.
description textWhat this source holds and who it serves, in plain words.
embedding_text textPlain text built from the name, description and coverage, for search indexes.
bibliographic bibliographicHow the work is cited: title, creators, publisher and edition.
holdings array of holdingThe repositories that hold this source, with call numbers.
coverage coverageWhat the source covers, including, for each place, which years it holds and the exact words to search with (routing lives only here).
access accessHow the source is reached, and the polite way to search it.
link_status enumWhether the source's address still works; a dead link is marked, never deleted.
last_verified_at timestampWhen the address was last confirmed to work.
discovered_via enumHow this source entry was first found.
discovered_via_as_written stringHow it was found, in the writer's own words, given when discovered_via is other.
external_ref stringThe link, category path or article title where this entry was found.
attribution attributionCredit to the human who compiled or contributed this entry (a credit never sets the living flag).
media_refs array of media_refFiles that show this source (a title page, a repository photograph), each described once on the record that captured it.

Added in 2.1

2.1 only adds; every 2.0 MaxSource stays valid. In the schema file's own words:

  • source_type (new field):
  • address (new field): MAXGEN 2.1 (G-14): where an archive or library is: its postal address in address_as_written, its town in place_as_written, and the MaxPlace in place_id; only on a source whose source_type is archive or library, or other for a church office, government office, cemetery, family papers or a private collection, and never a person's home address.

Everything 2.1 added

What changed from 1.13

source_url becomes optional; the provenance block is dissolved (status → link_status, asserted_by → created_by_task_id, asserted_at → created_at); coverage.time_period becomes coverage.span (a date block, no year cap); places use the place block. Added: bibliographic (title, creators, publisher, edition), holdings (which repository holds the original), is_living_flag (required), a wider source_type list, discovered_via.
