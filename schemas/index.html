MAXGEN v2.0 · twelve files, one version

The schemas

MAXGEN 2.0 is one release: eleven record schemas plus one shared building-blocks file. Every file is JSON Schema Draft 2020-12. All twelve files share one version number, and within 2.x every change is additive: a file valid under 2.0 stays valid under every 2.x.

MaxRecord

One MaxRecord is one document, copied word for word.

raw-record.schema.json

MaxPerson

One MaxPerson is one person, as a researched conclusion (holds no family links).

person.schema.json

MaxRelationship

One MaxRelationship is one family link, stored once: a family, a parent_child pair or an association.

relationship.schema.json

MaxTask

One MaxTask is one piece of work: research, an import, a review or a proof.

task-queue.schema.json

MaxSource

One MaxSource is one work, collection or repository.

source.schema.json

MaxPlace

One MaxPlace is one real place with its history.

place.schema.json

MaxGroup

One MaxGroup is one historical group (its own facts only; no member list).

group.schema.json

MaxEvent

One MaxEvent is the identity of one occasion (thin).

event.schema.json

MaxName

One MaxName is knowledge about one name.

name.schema.json

MaxRecognition

One MaxRecognition is one machine reading of an image.

recognition.schema.json

MaxDNA

One MaxDNA is one person's DNA test and its matches (always private).

dna.schema.json

Shared building blocks

maxgen-defs.schema.json is not a record type: no document is valid against it alone. It holds the parts every record schema uses: ids and small types, the date block, the place block, the evidence link (the part of every claim that says which evidence it rests on), the quote check, saved copies, regions and media pointers, roles and event types, the claim header, the common and lifecycle fields, and the task provenance block. Download the shared file.

Every file declares its own address in its $id. A record schema points into the shared file by a relative address, so all twelve files sit side by side in one folder. Validators load all twelve files into one registry and never fetch anything over the network; the addresses do not need to be reachable for validation to work. The fingerprints are also in SHA256SUMS.txt, and a machine-readable list of every version is at /schemas/maxgen/index.json.

MAXGEN 1.13 (archived)

The seven 1.13 schema files stay exactly as they were, at their permanent addresses under /schemas/maxgen/v1/ and /schemas/maxgen/v1.NN/. MAXGEN 2.0 does not read 1.x files. The 1.13 pages are kept for reference: MaxRecord · MaxPerson · MaxTask · MaxDNA · MaxSource · MaxRecognition · MaxName.

Check a record

Paste any JSON record into the browser validator to see whether it conforms. Nothing you paste leaves your computer.
