MAXGEN schema · v2.1

MaxRecognition

One MaxRecognition is one machine reading of an image.

Download MaxRecognition (2.1) All versions https://opengenealogyai.org/schemas/maxgen/v2/recognition.schema.json

SHA-256 ca72abecd356d4bee9bbc827c3213c231b95931d7884f9122ad744006e0f6e4e

Definition

MAXGEN 2.0 -- One MaxRecognition document is one machine reading (OCR of print or HTR of handwriting) of one image, kept with its per-word confidences so that readings of the same image can be compared; who or what made the reading is recorded on the task that produced it.

The schema's own description, word for word.

Fields

The top-level fields of a MaxRecognition document. Parts shared by every schema (the date block, the place block, the evidence link, the claim header and others) are defined once in the shared building-blocks file.

FieldTypeMeaning
recognition_id requireduuidRandom id of this reading, created once by its writer and never reused.
recognition_type requiredenumWhat kind of text was read: ocr for printed or typed text, htr for handwritten text, other (with recognition_type_as_written) for anything else.
recognition_type_as_written stringThe reading program's own word for the kind of reading, written when recognition_type is other.
image_url uriAddress of the image that was read, never invented; at least one of image_url and raw_record_id is required.
raw_record_id uuidThe MaxRecord whose image this reading read; at least one of image_url and raw_record_id is required.
copy_sha256 sha256Fingerprint of the saved copy that was read (described on raw_record_id, or on the live record that holds that copy), the same copy that evidence links cite.
region_id uuidThe marked region of that saved copy that was read, when only part of the image was read.
output_text requiredstringThe full text this reading produced, as plain text or as a JSON-encoded string of structured lines or words.
processed_at requiredtimestampWhen this reading was produced (UTC); renamed from the 1.x processing_date.
language langLanguage of the document that was read, as a language code such as de, la or en.
confidence confidenceOverall confidence the reader reported for the whole reading, 0 to 1, kept as reported and never computed by the kit.
word_confidences array of word_confidenceOne item per word read, with its confidence, how it was produced, other readings considered and where it sits on the image.
character_error_rate numberCharacter error rate measured against a checked reference text, when one exists.
word_error_rate numberWord error rate measured against a checked reference text, when one exists.
consensus_group_id uuidA grouping label shared by several readings of the same image so they can be compared; it names no MAXGEN document.
redistribution_license requiredlicenceLicence of this reading's text; tier2-private when the image is rights-restricted or anyone named may be alive.
is_living_flag requiredbooleanLiving A: true if anyone named in this reading may be alive, and true when unsure; a floor the kit only raises, and true requires tier2-private.
attribution attributionCredit for a human transcriber or the organization that made the reading; a credit never sets a living flag.
font_type enumPrinted readings: the main kind of typeface on the page (other with font_type_as_written).
font_type_as_written stringThe reader's own words for the typeface, written when font_type is other.
scan_dpi integerPrinted readings: the scan resolution of the image in dots per inch.
script_type enumHandwritten readings: the handwriting script family of the document (other with script_type_as_written).
script_type_as_written stringThe reader's own words for the script, written when script_type is other.
approx_century integerHandwritten readings: the rough age of the handwriting as the first year of its century (1800 means the 1800s).
searchable_variants array of stringEvery spelling this reading should be findable under, including uncertain readings and normalised forms.
read_blind booleanMAXGEN 2.1 (G-30): true when the image was read before the reader saw any index or other reading of it, so the reading is independent; false when it was read after seeing one.
based_on_recognition_id uuidMAXGEN 2.1 (G-30): the reading this one started from and corrected; what changed is worked out by comparing the two.
field_comparison array of field_comparisonMAXGEN 2.1 (G-11): how this reading compares with an index of the same image, field by field, as the reader judged it.

Added in 2.1

2.1 only adds; every 2.0 MaxRecognition stays valid. In the schema file's own words:

  • field_comparison.field (new field): The field compared, as written (name, age, birthplace ...).
  • field_comparison.index_value (new field): What the index says.
  • field_comparison.mention_ref (new field): Which person or line of the index the field belongs to, as the reader wrote it.
  • field_comparison.page_value (new field): What the image says, as read.
  • field_comparison.result (new field): The image and the index agree, differ, or the image is unclear there.
  • based_on_recognition_id (new field): MAXGEN 2.1 (G-30): the reading this one started from and corrected; what changed is worked out by comparing the two.
  • field_comparison (new field): MAXGEN 2.1 (G-11): how this reading compares with an index of the same image, field by field, as the reader judged it.
  • read_blind (new field): MAXGEN 2.1 (G-30): true when the image was read before the reader saw any index or other reading of it, so the reading is independent; false when it was read after seeing one.

Everything 2.1 added

What changed from 1.13

The 1.13 fields are kept. is_living_flag added (required); contributor removed; image_url and raw_record_id both optional but one required; copy_sha256 and region_id added (the same copy and region evidence cites); processing_date renamed processed_at; review_status, is_human_reviewed and is_independent removed (reviews are tasks; independence is computed).
