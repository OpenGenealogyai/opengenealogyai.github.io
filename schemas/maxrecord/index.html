MAXGEN schema · v2.1

MaxRecord

One MaxRecord is one document, copied word for word.

Download MaxRecord (2.1) All versions https://opengenealogyai.org/schemas/maxgen/v2/raw-record.schema.json

SHA-256 ad38d5a1d421bcd74389c2bddb6887d62a2c66ac88cf092f9af3e0d8d502bd67

Definition

MAXGEN 2.0 -- One MaxRecord is one original document (or one copy of it), copied word for word with every person it names and every event it records, so that one original equals one record.

The schema's own description, word for word.

Fields

The top-level fields of a MaxRecord document. Parts shared by every schema (the date block, the place block, the evidence link, the claim header and others) are defined once in the shared building-blocks file.

FieldTypeMeaning
record_id requireduuidThis record's permanent random id, created once by the writer and never recomputed or reused.
record_type requiredenumWhat kind of document this is; census_household holds a whole household, gazetteer_entry is an authored gazetteer or authority page, and dna_match_list is always tier2-private and living.
record_type_as_written stringThe document's or program's own words for its type, used with other.
redistribution_license requiredlicenceWhether this record may be shared, and under what licence; must be tier2-private while is_living_flag is true.
is_living_flag requiredbooleanLiving A: whether anyone this record names may be alive (unsure means true); true requires tier2-private, it is a floor that only rises, and privacy is always worked out again when read.
source_classification requiredsource_classificationWhether the document is an original, a copy or an authored work, and how first-hand its information is overall.
transcription_parts array of transcription_partThe document's text word for word, in labelled parts; a line that starts with [label] and one space carries that line label.
transcription_scope enumHow much of the document was transcribed; only complete_entry or complete_list can carry evidence of absence; required when transcription_parts is present.
transcription_sha256 sha256Helper-owned fingerprint of transcription_parts in canonical form, used to tell when quote checks are stale.
extraction_confidence confidenceHow faithfully the transcription follows the document, from 0 to 1; required when transcription_parts is present.
persons_mentioned array of mentionEvery person the document names, one mention each, as written.
events_documented array of event_entryThe events this document records, one entry each (one per child for twins); the helper gives each entry its own occurrence.
record_date dateThe date the entry or document was written, not the date of the event it records.
record_place place_refWhere the document was made, as written.
record_status enumWhether this is the first issue of the document or an amended, delayed or reissued one; lineage facts citing an amended, delayed or reissued record are flagged for review (R-18).
record_status_as_written stringThe document's own words for its status, used with other.
copied_from array of copy_stepThe step back toward the original that this copy was made from; required with at least one step when the source is derivative, and the full chain is found by following record ids, never copied here.
part_of_source_id uuidThe MaxSource (collection, book, film) this record belongs to; containment, kept apart from copying.
repository_as_written stringThe archive, library or family holding the document, as written.
collection_as_written stringThe collection the document sits in, as written.
locator locatorWhere the document sits in its collection: volume, page, line and so on.
original_key original_keyHelper-built stable name of the original document, used to refuse duplicates and to judge independence; never written by hand.
source_url uriThe web address where the document was read; optional, and never invented.
citation_as_written stringA footnote or citation string exactly as another program or publication gave it.
citation_template citation_templateA citation template another program used for this document, with its field values.
saved_copies array of saved_copyThe files this record captured, each described here once and keyed by fingerprint; frozen once stored apart from their descriptive fields.
media_refs array of media_refFiles described on another record that this record also uses.
attribution attributionCredit for the human who photographed, transcribed or compiled this record; a credit never sets a living flag.
rights_uri uriA web address stating the rights in this document.
sensitive_data_redacted booleanTrue when sensitive details (identity numbers, medical details) were left out of the transcription.
redaction_notes stringWhat was left out and why.
archive_ref stringA local path where this record is kept; private, never exported.
cited_record_ids array of uuidMAXGEN 2.1 (G-29): on a life_story record only, the documents the story draws on; each must exist (R-04), as MaxPlace lists its own.

Added in 2.1

2.1 only adds; every 2.0 MaxRecord stays valid. In the schema file's own words:

  • cited_record_ids (new field): MAXGEN 2.1 (G-29): on a life_story record only, the documents the story draws on; each must exist (R-04), as MaxPlace lists its own.
  • record_type: new allowed value life_story

Everything 2.1 added

What changed from 1.13

One original, one record, holding the whole entry. transcription becomes transcription_parts with permanent line labels, transcription_scope (complete entry, complete list, partial) and a kit-computed fingerprint. Added: persons_mentioned with a permanent mention_id, the page's own role words and is_living for every person; events_documented, the events the document records, each with information judged per event (each gets an occasion id); source_classification as a required core field (it was under extensions); copied_from (the copying chain, required for a derivative); part_of_source_id and locator; a kit-built original_key that refuses a second copy of the same original; record_status (amended, delayed, reissued); saved_copies and media_refs; citation_as_written and citation_template. source_url becomes optional, but "where it is" is required (an address, a saved copy, or a repository or source with a locator; never an invented URL). record_date is the date the entry was written. census_row is renamed census_household; new types include birth_register, death_register, tree_import, gazetteer_entry and dna_match_list. Removed: transcription, image_url, locations, repository, collection (now _as_written fields), language, alternate_names, digital_object_id, extracted_by, extracted_at.
