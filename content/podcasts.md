# The MAXGEN podcast

Each of the seven original schemas gets one conversation. Start with the overview if you are new, or jump to the schema you care about.

Subscribe in any podcast app with the feed address **`https://opengenealogyai.org/podcasts/feed.xml`**.

<p class="muted">These episodes were produced with an AI narration tool from written scripts by the standard's author, and describe MAXGEN v1.11. MAXGEN 2.0 changed a great deal since, so each episode links to <a href="/changelog/#v20-2026-10-16">what changed</a>. Where an episode and a schema page disagree, the schema page is authoritative. The four schemas new in 2.0 (MaxRelationship, MaxPlace, MaxGroup and MaxEvent) have no episode yet.</p>
