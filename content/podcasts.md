# The MAXGEN podcast

Each schema gets one conversation. Start with the overview if you are new, or jump to the schema you care about. Every episode has a written study guide with practice questions and a glossary.

Subscribe in any podcast app with the feed address **`https://opengenealogyai.org/podcasts/feed.xml`**.

<p class="muted">These episodes were produced with an AI narration tool from written scripts by the standard's author, and describe MAXGEN v1.11. Where a later release changed a detail, the schema pages on this site are authoritative.</p>
